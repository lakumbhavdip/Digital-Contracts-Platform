For database connection 
===================================
sudo -u postgres psql
--> psql -h localhost -U postgres6 -d tothiqv4
--> \l (for database list)
--> \c database_name (for switch database)
--> \dt (show all tabels)


For Database backup
=====================================
--> pg_dump -U postgres6 -d tothiqv4 -f DB_backup_02112023.sql


For Database import
=======================================
--> psql -h localhost -p 5432 -U postgres7 -d tothiqv5 -f dump.sql


For one table backup
======================================
--> \copy tablename to 'filename' csv; 
--> pg_dump -t (table_name) (database_name) > '(File_name).sql'

For database connection 
===================================
--> psql -h localhost -U (username) -d (database_name)
--> \l (for database list)
--> \c database_name (for switch database)
--> \dt (show all tabels)


For one Database backup
=====================================
--> pg_dump -U (username) -d (database_name) -f (File_name).sql


For one Database import
=======================================
--> psql -h (host) -p (port) -U (username) -d (database_name) -f "C:/Users/Finespun/Downloads/backup94.sql"



For one table backup
======================================
--> \copy tablename to 'filename' csv; 
--> pg_dump -t (table_name) (database_name) > '(File_name).sql'
